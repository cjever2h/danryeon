# 단련 | 죄수운동 마스터

단계적 맨몸 운동 학습을 위한 한국어 웹앱입니다.

- 6개 기본 동작 수준 진단과 시작 단계 추천
- 주 3회 회복 포함 훈련 일정
- 훈련 중 세트 목표, 반복 카운터, 휴식 타이머
- 브라우저 로컬 저장 기반 훈련 기록, 통계, JSON 내보내기
- 운동 가이드 및 훈련 화면 내 자세 안내
- 6가지 기본 동작별 오리지널 삽화와 클릭 가능한 10단계 진행 차트
- 휴대폰 폭에 맞춘 터치 영역, 가로 스크롤 단계 차트, 하단 탭·세션 시트
- 반응형 모바일·데스크톱 인터페이스

## 실행
`index.html`을 브라우저에서 열면 됩니다. 빌드·서버·외부 서비스가 필요하지 않습니다.

## 데이터/개인정보
측정 결과와 훈련 기록은 현재 기기의 브라우저 `localStorage`에만 저장됩니다. 다른 기기와 동기화되지 않습니다. JSON 내보내기로 백업할 수 있습니다. 사용자 인증이나 서버 데이터베이스를 사용하지 않습니다.

## 훈련 안전
건강상 문제가 있거나 통증·어지럼증이 발생하면 운동을 중단하고 전문가와 상담하세요. 자세가 무너지기 전에 반복을 멈추고 충분히 회복하세요. 본 앱은 의료·재활 지침을 대체하지 않습니다.

## 자료 기반
첨부된 죄수운동법 PDF의 점진적 난이도/단계 훈련 원칙을 참고해 6개 기본 동작의 단계 이름을 요약·재구성했습니다. 본 앱은 책의 원문을 제공하지 않습니다. 개별 운동 단계와 반복 목표는 보수적으로 앱에 맞게 단순화했습니다.
